# 💻 Digital VLSI Design

This repository contains the implementation of fundamental **Digital VLSI circuits** covering combinational, sequential, and arithmetic building blocks.

---

## 🚀 Modules Included

### 🔹 Basic Logic Gates

* AND, OR, NOT (Inverter)
* NAND, NOR, XOR, XNOR

### 🔹 Combinational Circuits

* Half Adder & Full Adder
* Multiplexer (MUX) & Demultiplexer (DEMUX)
* Encoder & Decoder
* Magnitude Comparator

### 🔹 Sequential Circuits

* D Flip-Flop
* Master-Slave Flip-Flop
* Counters
* Shift Registers

### 🔹 Arithmetic Circuits

* Ripple Carry Adder (RCA)
* Array Multiplier

### 🔹 Special Circuits

* Tri-state Buffer & Inverter
* Pseudo Logic / VTC Analysis
